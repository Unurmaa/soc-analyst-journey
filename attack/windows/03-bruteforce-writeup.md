# Windows Brute-Force Attack Write-up (B дасгал)

## 1. Дасгалын тойм ба Зорилго
Энэхүү дасгалаар Windows орчинд Remote Desktop Protocol (RDP) эсвэл SMB/WinRM ашиглан хийгдэж буй brute-force (хандалтын эрх таах) халдлагыг илрүүлэх, PowerShell болон SIEM (Wazuh) системүүд дээр үүссэн логуудыг шинжлэх арга зүйд суралцсан болно.

## 3. PowerShell (`Get-WinEvent`) vs Wazuh үр дүнгийн харьцуулалт (5 өгүүлбэр)
1. PowerShell-ийн `Get-WinEvent` ашиглан Security лог шүүхэд тухайн IP хаягаас ирсэн олон тооны `4625` (Failed Logon) event-үүд цаг хугацааны дарааллаар ямар ч шүүлтүүргүйгээр шууд түүхий хэлбэрээр харагддаг.
2. Харин Wazuh систем нь эдгээр сарнисан олон удаагийн бүтэлгүйтсэн логуудыг хооронд нь холбож (correlation хийн) тодорхой босго (threshold)-ын дараа нэгдсэн анхааруулга (alert) болгон хувиргадаг.
3. PowerShell ашиглан гараар шинжлэх нь шуурхай шалгалт хийхэд тохиромжтой боловч бодит цаг хугацаанд (real-time) тасралтгүй хянах боломж хязгаарлагдмал байдаг.
4. Wazuh нь Agent суулгасан төхөөрөмжөөс логуудыг шууд төв сервер рүү татан авч, rule-д суурилсан автомат илрүүлэлтийг хийж админд мэдэгддэг давуу талтай.
5. Иймд эдгээр хоёр арга хэрэгсэл нь нэг нэгнээ нөхөж, нэг бол өдөр тутмын хяналт тавих (Wazuh) эсвэл гүнзгийрүүлсэн forensic шинжилгээ хийхэд (PowerShell) тус тус оновчтой ашиглагддаг.
