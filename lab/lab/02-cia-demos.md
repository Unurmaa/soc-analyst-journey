# CIA гурвалжны демо туршилтуудын тайлан

## A. Confidentiality (Нууцлал) - Base64 Decode
* **Screenshot:** (tcpdump болон base64 decode хийсэн зургийг оруулах)
* **Тайлбар:** Шифрлэлтгүй HTTP протокол ашиглан нэвтрэх мэдээлэл явуулахад сүлжээгээр чагнагдаж (Sniffing), хэрэглэгчийн нэр, нууц үг Base64 код хэлбэрээр баригдсан. Base64 нь шифрлэлт биш тул шууд задлахад `alice:Summer2026!` гэсэн нууц үг ил болсон нь **Confidentiality (Нууцлал)** зарчим зөрчигдсөнийг нотолж байна.

## B. Integrity (Бүрэн бүтэн байдал) - FIM & Hash
* **Screenshot:** (salary.txt файл дээр hash шалгасан болон FIM alert зургийг оруулах)
* **Тайлбар:** Файлын агуулгыг өөрчлөхөд SHA256 хэш утга шал өөр болж хувирсан (`62E47C5B...` -> `2FEDAA45...`). Wazuh FIM модуль үүнийг илрүүлж Rule 550 (checksum changed) алерт өгсөн нь өгөгдөл зөвшөөрөлгүйгээр өөрчлөгдсөнийг илтгэж, **Integrity (Бүрэн бүтэн байдал)** алдагдсаныг харуулж байна.

## C. Availability (Бэлэн байдал) - Agent Stop/Start
* **Screenshot:** (Wazuh agent stopped/started болон rule 506/503 зургийг оруулах)
* **Тайлбар:** Агент үйлчилгээ гэнэт зогсоход Rule 506 (`Wazuh agent stopped`) алерт бүртгэгдсэн. Халдагчид EDR/Agent-ийг унтрааж хяналтаас зугтах оролдлого хийдэг (ATT&CK T1562.001) тул энэ нь системийн хяналт болон аюулгүй байдлын **Availability (Бэлэн байдал/Хяналт)** тасрах эрсдэлтэйг сануулдаг.
